# Canary perturbation detector

Code, data and raw logs for the paper

> **Black-Box Detection of Data Contamination in Large Language Models Using
> Evidence-Level Perturbations**
> Ximing Chen, 2026

The repository contains everything needed to regenerate the numeric tables of the
paper from the raw model outputs, plus the scripts that generated the canary suites,
ran the models and built the contaminated models.

## Layout

| path | content |
| --- | --- |
| `experiment/scripts/` | all code (suite generation, validation, API runs, fine-tuning, local evaluation, table and figure generation) |
| `experiment/data/` | the canary suites (`canary_items.json`, `canary_train.json`, `canary_heldout.json`), the easy suite in `v3/`, and the superseded first-generation suite in `legacy/` |
| `experiment/results/` | every run as JSONL (one record per item × form), plus summaries and logs; nothing was deleted |
| `figures/` | the figure files produced by `plot_figs.py` (the paper reports the dose experiment as a table, see below) |
| `docs/` | data description and a table-by-table reproduction guide |
| `操作手册.md` | operations manual in Chinese: publishing to GitHub, backfilling the paper URL, maintenance |

## Requirements

Python 3.10 or newer. Reproducing the tables and validating the suite needs only
the standard library; plotting needs `matplotlib`; fine-tuning and local evaluation
need `torch`, `transformers`, `peft` and `datasets` (see `requirements.txt`).

```bash
python -m pip install -r requirements.txt
```

## Reproduce the tables

Run from the repository root:

```bash
python experiment/scripts/paper_tables.py
```

This prints Tables I, II, IV and V of the paper and re-renders Table III, all from
`experiment/results/` and `experiment/data/`. The statistic is the item-paired
accuracy drop

```
Delta_m = mean over items of (1/|F|) * sum_{f in F} (y_orig - y_f)
```

with `F_Q = {rename, paraphrase, table}` for the question-level family,
`F_E = {perm, rrename, both}` for the evidence-level family, and `swap` reported as
a single form. Intervals are 95% percentile bootstrap intervals that resample
**items**, not queries (4000 draws, seed 7).

Other entry points:

```bash
python experiment/scripts/validate_forms.py     # structural checks of the suite
python experiment/scripts/plot_figs.py          # figures/variance.png and figures/dose_response.png
python experiment/scripts/summarize_all.py --run qwencontam4 contaminated
python experiment/scripts/final_stats.py
python experiment/scripts/seed_table.py
python experiment/scripts/dose_table.py
```

`plot_figs.py` writes the dose-response figure as well; the paper reports that
experiment as Table IV and uses only the variance figure.

## Reproduce a run

The API controls are queried through an OpenAI-compatible endpoint. Copy
`.env.example` to `experiment/.env`, fill in `DEEPSEEK_API_KEY`, then

```bash
python experiment/scripts/pilot_contamination.py gen --items 100 --rows 6 --op share --seed 20261231
python experiment/scripts/validate_forms.py
python experiment/scripts/pilot_contamination.py run --tag myrun --models deepseek-chat
python experiment/scripts/pilot_contamination.py analyze --tag myrun --exclude-forms distractor
```

The contaminated models are LoRA adapters on Qwen2.5-Instruct, trained on the exact
original rendering of the 100 canary items:

```bash
python experiment/scripts/finetune_canary.py data
python experiment/scripts/finetune_canary.py train --model Qwen/Qwen2.5-1.5B-Instruct --epochs 30 --name my-adapter
python experiment/scripts/local_eval.py --name my-model --adapter experiment/models/my-adapter --tag myrun
python experiment/scripts/local_eval.py --name my-model --adapter experiment/models/my-adapter --heldout --tag myrun-heldout
```

The adapters used in the paper are about 150–240 MB each (roughly 2.3 GB in total)
and are **not** committed. They are regenerated by the training command above; the
epochs and seeds are reported in the paper.

## Raw results and model names

`experiment/results/` keeps every run, including the runs that failed and the
superseded suite version. Model identifiers are the ones recorded at run time. The
two commercial controls appear in the paper as vendor A and vendor B; they are
`deepseek-chat` and `qwen-plus` respectively.
